# X 推文转图片（Chrome 插件）

把 X（推特）里一条推文的**文字 + 图片**一键渲染成一张精美卡片图片，方便分享给家人朋友。

纯本地运行，不上传任何数据；用 Canvas 自己绘制卡片，不依赖第三方库。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「**开发者模式 / Developer mode**」
3. 点「**加载已解压的扩展程序 / Load unpacked**」
4. 选择本文件夹 `shareX`
5. 装好后可以把它固定到工具栏

## 使用

1. 打开 [x.com](https://x.com)，进入你想分享的那条推文
2. 推文底部操作栏会多出一个 **📸** 按钮，点它
3. 弹窗里预览生成的图片，点：
   - **⬇️ 下载图片** — 存成 PNG
   - **📋 复制到剪贴板** — 直接粘贴到微信 / 备忘录等

## 说明

- 支持正文（含 emoji、换行）、作者头像/昵称、最多 4 张配图、发布日期。
- 图片通过后台抓取高清版，避免画到画布时跨域报错。
- 只在 `x.com` / `twitter.com` 上运行，不读取其它网站。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 插件配置（MV3） |
| `content.js` | 注入按钮、抽取推文、Canvas 渲染、预览弹窗 |
| `content.css` | 按钮与弹窗样式 |
| `background.js` | service worker，跨域抓取图片转 data URL |
| `popup.html` | 工具栏弹窗（使用说明） |
